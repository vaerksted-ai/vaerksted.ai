# Værksted — static site

The full deployable static site for [vaerksted.ai](https://vaerksted.ai).
Single-page landing, no build step, no JavaScript framework.
Drop the folder on any static host and you're live.

## Files

| File | Purpose |
|---|---|
| `index.html` | Landing page. Full content. |
| `404.html` | Error page (same aesthetic). |
| `favicon.svg` | Modern browser favicon (gold-rimmed medallion, the Æ in the Bifröst gradient). |
| `favicon.ico` | Legacy fallback (16, 32, 48, 64 px embedded). |
| `apple-touch-icon.png` | iOS home-screen icon (180×180). |
| `icon-192.png` / `icon-512.png` | PWA / Android home-screen. |
| `icon-maskable-512.png` | Android adaptive icon (seal kept inside the safe zone). |
| `stars.svg` | Cosmic starfield backdrop (generated by `render_stars.py`). |
| `og-image.png` | Social preview (1200×630) — shown on X, LinkedIn, iMessage, Slack, etc. |
| `og-image.svg` | Editable source for the OG image. |
| `brand/` | Brand kit — logo avatar, seal, wordmark, lockup, GitHub social preview (see below). |
| `manifest.webmanifest` | PWA manifest (theme color, icons). |
| `robots.txt` | Allow all crawlers, point at sitemap. |
| `sitemap.xml` | Every live, indexable URL: absolute, trailing slash, `lastmod` = last material content change. No `changefreq` or `priority`. Add an entry in the same PR as the page. |
| `llms.txt` | Plain-text summary for LLMs. Lists live pages only. Update in the same PR as the page. |
| `wrangler.jsonc` | Cloudflare config. Not served (excluded by the Pages build command, see Deployment). |
| `render_brand.py` / `render_stars.py` | Generators for the brand kit, icons, share image and starfield. Not served. |
| `CNAME` | Custom-domain mapping for GitHub Pages only. Delete elsewhere. |

All assets are referenced by absolute paths (`/favicon.svg` etc.), so the site must be served from the **root** of the domain, not a subpath.

## Deployment

### Cloudflare Pages (recommended for `.ai` domains)

1. Push this folder to a new GitHub repo.
2. Cloudflare Dashboard → Workers & Pages → Create → connect the repo.
3. Build command: `mkdir -p dist && tar --exclude=./dist --exclude=./.git --exclude=./README.md --exclude=./wrangler.jsonc --exclude=./render_brand.py --exclude=./render_stars.py --exclude=./CNAME -c . | tar -x -C dist`. Build output: `dist`. Pages has no ignore file, so this command is what keeps the repo files in the list above from being served. It is a dashboard setting and applies to every branch.
4. Custom domains tab → add `vaerksted.ai` and `www.vaerksted.ai`.
5. Cloudflare auto-provisions SSL. Done.

### Netlify

1. Drag-and-drop the folder onto [app.netlify.com/drop](https://app.netlify.com/drop).
2. Domain settings → add custom domain → follow DNS instructions.
3. Domain settings → add custom domain → follow DNS instructions.
